# Optional network inventory (TASK-S2-001)

Fixed query: `SELECT interface, address, mask FROM interface_addresses`.
Official primary definition verified at https://raw.githubusercontent.com/osquery/osquery/5.12.1/specs/interface_addresses.table (interface/address/mask are TEXT; Windows adds friendly_name, which is excluded). This is schema compatibility evidence, not native execution proof. No native binary, installation or production scan was performed.

Each batch may include `network_interfaces`, an array of at most 256 objects containing only interface (nonempty, <=128 characters, no control characters), address and mask. Both literals must share IPv4/IPv6 family; masks must be contiguous network masks. Prefix-length strings, zone identifiers, names, malformed literals and unknown fields are rejected. Canonical IP and network CIDR are derived server-side. An entire complete snapshot is repeated in each existing split batch; it is never chunked into partial address sets. The original row split/queue byte limit and exact ACK contract are unchanged.

Missing property means unknown/not observed: legacy queued batches and network query failures preserve saved addresses. A valid empty array means a complete successful empty observation: current Host addresses become empty; historical NetworkInterface rows remain. Failed optional network reads omit the property; all other query errors retain the prior fail behavior. Invalid returned rows reject the batch, rather than pretend that an empty observation succeeded.

Host identity remains host_uuid. Interface identity is a SHA-256-derived UUID over host ID, interface name and canonical address. Duplicate rows upsert the same identity. The current Host observation timestamp acts as the monotonic guard under the existing transaction/row lock. Older complete snapshots cannot overwrite a newer Host observation, including a newer legacy observation with unknown IP state; this conservatively preserves the known addresses rather than reconstruct independent per-field freshness without schema changes. Equal timestamps use existing last-arrival-wins policy; exact replay is idempotent. First seen remains the original insertion timestamp. Interface rows absent from a later snapshot are retained, with their original observation metadata; no retirement or deletion is inferred.

No owner/site changes, reachability inference, DNS resolution or schema migration. is_public remains the existing false default: this task makes no public reachability assertion from an address alone. Raw source evidence references remain available in storage but excluded from inventory API responses. Privacy boundaries, Cloudflare GET-only, osquery SELECT-only and closed Sprint0/1 limits remain.
